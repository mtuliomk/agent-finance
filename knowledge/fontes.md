# Política de fontes

O catálogo é descoberta, não evidência nem lista exclusiva. Consulte `make fontes-listar TOPIC=TEMA` (macroeconomia, acoes, fundos, credito, tributacao, produtos, noticias); busque fora quando necessário. Cite documento/dado efetivamente aberto, data do fato/consulta, período e unidade; verificação do link não valida publicações futuras.

Prefira órgão, emissor e documento primário. Imprensa/comerciais dão contexto e descoberta; confirme alegações materiais. Oferta XP/BTG ou pitch comprova apenas a oferta apresentada, não execução, segurança ou vantagem.

| Informação | Destino |
| --- | --- |
| Preço, indicador, oferta, rating, notícia, resultado, regra mutável | Web sob demanda; futuro MCP autenticado quando disponível |
| Princípio/método durável e vínculo normativo | `knowledge/`, sem copiar páginas |
| Posição pessoal ou série para comparação reproduzível | `state/`, com origem, data, unidade e versão |
| Documento original | `inbox/` na triagem; `state/raw/` após ingestão |
| Raciocínio/decisão histórica | `decisions/`, sob a regra de registro de `AGENTS.md` |

Cotação isolada não vira state sem uso recorrente definido. Cadastre só canais estáveis para perguntas recorrentes, com finalidade e limites; não cada artigo/oferta. Para manter o catálogo, use `skills/gerir-fontes/SKILL.md`.
